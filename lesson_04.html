Тема пари

В ході пари ми познайомимось з тим, як за допомогою Grid будувати не просто сітку, а повноцінний макет сторінки та адаптивні картки.

1. Позиціонування елементів

span і лінії сітки

Елемент можна розтягувати на кілька колонок або рядків.

Це зручно для акцентних карток, банерів або великих блоків.

2. Іменовані області і адаптивна магія

grid-template-areas

Named areas дозволяють читати макет майже як ASCII-схему.

Такий підхід дуже зручний для header, sidebar, content, footer.

CSS

.layout { display: grid; grid-template-areas: "header header" "sidebar content" "footer footer"; }

minmax і auto-fit

Патерн repeat(auto-fit, minmax(240px, 1fr)) — один із найкорисніших у сучасному CSS.

Він дозволяє робити адаптивні картки навіть без media queries.

Це один із найпрактичніших прикладів Grid для реальних сайтів.

Практична робота на парі

  1. Створіть макет через grid-template-areas.
  2. Зробіть один блок ширшим за інші через span.
  3. Побудуйте адаптивну сітку карток через auto-fit і minmax.
  4. Порівняйте auto-fit та auto-fill на практиці.

Домашнє завдання

  1. Створіть сторінку портфоліо або блогу.
  2. Шапку, сайдбар, основний контент і футер побудуйте через named areas.
  3. Блок з роботами зробіть через repeat(auto-fit, minmax(240px, 1fr)).
  4. Один із елементів у сітці зробіть акцентним і розтягніть на 2 колонки.
